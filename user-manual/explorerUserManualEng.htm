Heurist Explorer

Explorer is the module that allows filtering, analysing, visualising and publishing data in your database. You define query sources (what to show), look at them in independent presentation modules (how to show it), and publish the result as a standalone page or a website.

1. Filter builder and source editor

Search on the toolbar opens the Query Source editor. It defines a query source: the query and the settings the presentation modules use with it. It can sit on the left (Vertical) or above the modules (Horizontal); choose with the … button.

Inline query helper

Type a query in the query box. The helper suggests record types, fields and operators as you type, and shows the query as a sentence below the box. Press Enter or Filter to run it.

Filter Builder

Builder opens the Filter Builder, where a query is put together from conditions without typing the query language.

Parameterized filter and Filter Form

A condition can be a parameter instead of a fixed value. A query with parameters is shown as a Filter Form: the user fills in the values (text, dates, lists, facets) and runs the search. This replaces the former faceted search.

Geographic, time and column fields

More (in the … menu) shows the presentation settings: which fields Map uses for geometry and Timeline for dates (also through linked records, when the records have none of their own), and which columns Data shows.

Expansion rules

Rules that add linked and related records to the result, level by level. Graph uses them to expand the network; Data can show each level.

Save stores the query with its settings as a Query Source; Add puts a saved source into your Workspace.

2. Saved filters and sources on the toolbar

Filters, Entities (record types) and Sources list what can be opened in the Query Source editor.

Favorites

Star a filter, record type or source to keep it in Favorites.

Workspace

A saved working set of query sources you are working with now.

Subsets

Restrict further searches to a subset of records.

3. Presentation modules

Each module is an independent application that shows the current result and selection; selecting records in one module highlights them in the others. Each can also be published on its own.

  • Data: the result as a list, table or cards.
  • Map: records with geographic data, in layers.
  • Graph: records and their links and relationships as a network.
  • Timeline: records with dates, in bands.
  • Record view: the full content of the selected record.

Modules have their own manuals, opened with the help button in the module.

Layout configuration

Explorer configuration (Options, the gear button on the toolbar) sets the toolbar position and button size, and which pane each module occupies. Several modules in one pane work as tabs: one is visible at a time.

Export

Export (right toolbar) writes the records of the current data source into a file. The file is made on the server; when it is ready, a link downloads it. Only you can download it, and it is kept for 24 hours. You can close the tool or reload the page: a running export continues and is shown again when you open Export. Stop ends it. Export results lists your finished exports: download them, open them in a new tab, or mark them and remove them. A new export is refused while your export results take more than 100 MB.

  • Scope: the current result, the selected records, or one record type of the result. The tool follows the current data source and selection.
  • Format: XML (HML, can be imported into another Heurist database; the default), JSON, CSV or TSV (one table per record type; several tables are packed in a zip), GeoJSON, KML or Gephi (GEXF, at most 10,000 records).
  • Columns (CSV, TSV, GeoJSON, KML, Gephi): for each record type choose Minimal (ID, record type, title), Metadata (also URL, dates, owner, visibility), All (also every field) or Custom (pick and drag the fields). Use data source settings adds the column, geographic and time fields of the data source. In CSV the first column is always H-ID, the record ID.
  • Expansion rules (XML, JSON, Gephi): also export linked records - through any link of a kind up to 4 levels, through the rules of the data source, or through custom rules for this export only. Each record is written once.
  • Value formats (formats with columns): temporals raw or human readable; files as URL, full information or ID; titles of pointed records; terms with their hierarchy. XML and JSON write the values as stored.
  • Additional properties: CSV options (separator, quote, separator of repeated values, header row, line ends); for XML and JSON, Include human-readable names and local IDs for everything - without it record types, fields and terms are identified by concept codes only.
  • Output: a record limit (All, 50 ... 500K) and the file name.

The number of records in one export is limited by the database setting (100,000 by default, expanded records included).
