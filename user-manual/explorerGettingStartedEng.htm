Query Source editor

This is where you define what Explorer shows: a query together with the settings the presentation modules use with it. All modules show its result.

Inline query helper

Type a query here. The helper suggests record types, fields and operators as you type, and shows the query as a sentence below the box.

Press Enter or Filter to run it.

Filter Builder

Put a query together from conditions, without typing the query language.

Parameterized filter and Filter Form

In the Filter Builder a condition can be a parameter instead of a fixed value. A query with parameters is shown as a Filter Form: fill in the values (text, dates, lists, facets) and run the search. It replaces the former faceted search.

Geographic, time and column fields

Which fields Map uses for geometry and Timeline for dates - also through linked records, when the records have none of their own - and which columns Data shows.

Expansion rules

Rules that add linked and related records to the result, level by level. Graph uses them to expand the network; Data can show each level.

Save and Add

Save stores the query with its settings as a Query Source, to reuse and publish. Add puts a saved source into your Workspace.

Layout and more options

Place the editor on the left (Vertical) or above the modules (Horizontal), and show or hide the settings with More.

Search

Shows or hides the Query Source editor.

Filters, Entities and Sources

Saved filters, record types and saved Query Sources. Pick one to open it in the editor and show its result.

Favorites

Star a filter, record type or source to keep it here.

History

The queries and sources you used recently. Explorer reopens the last one when it starts.

Workspace

A saved working set of the Query Sources you are working with now.

Subsets

Restrict further searches to a subset of records.

Result

The result as a list, table or cards. Each module is independent: show, hide or move it as you need; selecting records in one module highlights them in the others.

Map

Records with geographic data, in layers. Each layer can show its records in Data.

Graph

Records and their links and relationships as a network, expanded with the expansion rules.

Timeline

Records with dates, in bands.

Record view

The full content of the selected record.

Layout configuration

Toolbar position and button size, and which pane each module occupies. Several modules in one pane work as tabs: one is visible at a time.

Tools

Reports, Crosstabs, Actions and Export work on the current result or selection.

Publication

Publish a module or a set of modules with your Query Sources as a standalone page or a website.
