Heurist Explorer

Explorer réunit les vues données, carte, chronologie et graphe autour d'une source de données et d'une sélection partagées.

Panneau de contrôle

Nouvelle recherche ouvre le sélecteur de recherche/filtre. Vues de données ouvertes affiche les vues de données présentes dans l'espace de travail.

Exporter

Exporter (barre de droite) écrit les enregistrements de la source de données courante dans un fichier. Le fichier est créé sur le serveur ; quand il est prêt, un lien permet de le télécharger. Vous seul pouvez le télécharger ; il est conservé 7 jours. Un export en cours continue si vous fermez l'outil ou rechargez la page ; Arrêter l'interrompt.

  • Portée : le résultat courant, les enregistrements sélectionnés ou certains types d'enregistrements du résultat.
  • Format : CSV ou TSV (un tableau par type d'enregistrement, regroupés dans un zip), JSON, GeoJSON, KML, XML (HML, importable dans une autre base Heurist) ou Gephi (GEXF).
  • Colonnes (CSV, TSV, GeoJSON, KML, Gephi) : les champs de chaque type d'enregistrement, éventuellement repris des champs de colonnes de la source. En CSV la première colonne est toujours H-ID. Un terme peut être écrit comme Terme, Code, ID de concept, Description ou ID interne.
  • Règles d'expansion : exporter aussi les enregistrements atteints par les règles ; chaque enregistrement est écrit une seule fois.
  • Formats des valeurs, options CSV, nombre maximum d'enregistrements et nom du fichier.

Carte narrative

Une carte narrative raconte l'histoire d'un enregistrement, le sujet (une personne, une expédition), avec les enregistrements qui la décrivent dans le temps et sur la carte, les éléments du récit (les événements de la vie de la personne, les campements de l'expédition). Le récit est affiché dans le panneau de l'outil ; l'élément courant est affiché sur la Carte. Une carte narrative est enregistrée comme un enregistrement (Presentation set) et peut être placée sur une page de site web.

  • Barre d'outils : Nouveau récit ; la liste des cartes narratives ; Éditeur du récit affiche ou masque la configuration ; le crayon modifie l'enregistrement (nom, propriétaire, visibilité) ; Enregistrer ; Supprimer (refusé tant que des pages web l'utilisent) ; Exécuter affiche les sujets comme résultat et le récit du premier.
  • Source : la requête des sujets ; les éléments du récit, trouvés par une règle d'expansion depuis le sujet (tous d'un seul type) ; leur ordre ; l'information de début et de fin ; le nombre maximal d'éléments.
  • Présentation : le modèle d'un élément ; Vertical, Horizontal, Carrousel ou Onglets ; la place de l'information de début et de fin ; les textes affichés avant le choix d'un sujet et quand un sujet n'a pas de récit.
  • Cartographie : le document cartographique de fond ; les lieux d'un élément (début, transition, fin) ; une ligne entre eux ; les lieux de tout le récit gardés sur la carte ; la durée du déplacement ; la symbologie.

La plupart des changements sont affichés aussitôt. Une nouvelle requête, règle ou carte de fond est appliquée avec Appliquer. Les changements ne sont gardés qu'après Enregistrer.
