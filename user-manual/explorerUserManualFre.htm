Heurist Explorer

Explorer réunit les vues données, carte, chronologie et graphe autour d'une source de données et d'une sélection partagées.

Panneau de contrôle

Nouvelle recherche ouvre le sélecteur de recherche/filtre. Vues de données ouvertes affiche les vues de données présentes dans l'espace de travail.

Exporter

Exporter (barre de droite) écrit les enregistrements de la source de données courante dans un fichier. Le fichier est créé sur le serveur ; quand il est prêt, un lien permet de le télécharger. Vous seul pouvez le télécharger ; il est conservé 7 jours. Un export en cours continue si vous fermez l'outil ou rechargez la page ; Arrêter l'interrompt.

  • Portée : le résultat courant, les enregistrements sélectionnés ou certains types d'enregistrements du résultat.
  • Format : CSV ou TSV (un tableau par type d'enregistrement, regroupés dans un zip), JSON, GeoJSON, KML, XML (HML, importable dans une autre base Heurist) ou Gephi (GEXF).
  • Colonnes (CSV, TSV, GeoJSON, KML, Gephi) : les champs de chaque type d'enregistrement, éventuellement repris des champs de colonnes de la source. En CSV la première colonne est toujours H-ID. Un terme peut être écrit comme Terme, Code, ID de concept, Description ou ID interne.
  • Règles d'expansion : exporter aussi les enregistrements atteints par les règles ; chaque enregistrement est écrit une seule fois.
  • Formats des valeurs, options CSV, nombre maximum d'enregistrements et nom du fichier.
