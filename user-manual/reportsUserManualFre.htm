Rapports Heurist

Le gestionnaire de rapports liste les modèles de rapport Smarty de la base. Un rapport est un enregistrement Custom Report (titre, description, fichier modèle, indicateur « fiche »); le texte du modèle est conservé dans un fichier. Les modèles sans enregistrement sont listés sous Modèles sans enregistrement de rapport et peuvent en recevoir un.

Deux sortes de rapport

  • Un seul enregistrement (fiche) : affiche un enregistrement. Ces rapports sont proposés pour les popups, les fiches et la vue enregistrement de Carte, Données, Graphe et Vue enregistrement.
  • Ensemble d'enregistrements : un rapport sur de nombreux enregistrements. Il n'est pas exécuté à la demande : il est généré dans un fichier en arrière-plan, et ce fichier peut être utilisé dans les sites web.

Modifier un modèle

Choisissez un rapport et cliquez Modifier le modèle. Placez le curseur dans le texte, choisissez un type d'enregistrement à droite et cliquez un champ pour l'insérer. Les options d'insertion décident si le nom du champ, un saut de ligne, un test de valeur vide ou une boucle pour les valeurs répétées sont ajoutés. Pour un champ de vocabulaire choisissez son libellé, son code ou son identifiant interne. Insérer un motif ajoute des blocs prêts à l'emploi (boucle d'enregistrements, tableau, ...).

Tester exécute le modèle tel qu'il est dans l'éditeur (enregistré ou non) sur les enregistrements sélectionnés, ou sur les 50 premiers du résultat courant. Un rapport d'enregistrement unique (fiche) est testé sur un seul enregistrement : le premier enregistrement sélectionné, ou le premier du résultat. Le test peut être arrêté et a une durée limite.

Par défaut, le résultat d'un rapport ne peut pas exécuter de JavaScript ni utiliser de blocs de style : ils sont supprimés, et la barre d'outils affiche « CSS et Javascript sont désactivés par défaut ». L'administrateur du serveur peut autoriser une base (fichier js_in_database_authorised.txt sur le serveur) ; les scripts s'exécutent alors dans le résultat, par exemple la visionneuse des vignettes d'images.

Génération et planifications

Générer écrit un rapport pour le résultat courant ou une Query Source dans un fichier. Cela se fait en arrière-plan : la progression est affichée et Arrêter y met fin. La génération continue si vous fermez le gestionnaire de rapports ou rechargez la page ; à votre retour, elle est de nouveau affichée avec sa progression. Une seule génération à la fois est possible. Un nouveau Test remplace un test encore en cours. Une planification (enregistrement Custom Report Schedule) régénère un fichier de rapport à partir d'une Query Source à intervalle régulier. Seuls le groupe propriétaire d'un rapport et le propriétaire de la base peuvent ajouter des planifications. Les rapports planifiés ne contiennent que des enregistrements publics.
