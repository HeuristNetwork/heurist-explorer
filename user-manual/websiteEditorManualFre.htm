Éditeur de sites web Heurist

L'éditeur montre les pages du site à gauche et un aperçu de la page choisie à droite. La barre d'outils en haut contient Propriétés (la fiche du site ou de la page), Styles (couleurs, polices et styles communs de tout le site), Vérifier (le format de toutes les pages et les fiches qu'un visiteur ne peut pas voir), Ouvrir (le site enregistré dans un nouvel onglet), l'aide et Fermer.

Onglet Site : les pages du site

  • Faites glisser les pages pour changer leur ordre dans le menu principal ; déposez une page sur une autre pour en faire une sous-page.
  • Ajoutez une page avec Ajouter une page sur Accueil, une sous-page avec + d'une page ; × retire une page du site.
  • Cliquez sur En-tête, Accueil, Pied de page ou une page pour la modifier dans l'onglet Page.

Onglet Page : les éléments d'une page

  • Faites glisser les éléments pour changer leur ordre ; les groupes, onglets et accordéons contiennent d'autres éléments.
  • + de la page, d'un groupe, d'onglets ou d'un accordéon ajoute un élément (onglets et accordéons : un nouveau panneau).
  • Le crayon d'un texte (ou un double-clic) ouvre Modifier le texte.
  • La roue dentée d'un élément (ou un double-clic) ouvre son panneau ; la roue dentée sous l'arbre affiche ou masque le panneau de l'élément choisi. La corbeille supprime l'élément.
  • Choisissez un élément dans l'arbre ou dans l'aperçu. Les modifications sont visibles tout de suite et gardées jusqu'à Enregistrer la page ou Abandonner ; Annuler et Rétablir les parcourent.
  • Un clic sur un lien d'un menu, du fil d'Ariane ou sur le logo dans l'aperçu ouvre sa page.

Le panneau d'un élément

Le panneau a deux onglets :

  • Configuration : ce que l'élément montre (ses fiches, fichiers, légende ou réglages de module), sa Présentation (comment il apparaît quand il entre dans la fenêtre : fondu, glissement, zoom, ou Masqué au départ) et son Identification : l'identifiant système créé par Heurist et un Nom de votre choix (lettres, chiffres, _ et -, unique sur la page). Un élément nommé peut être la cible de l'action Afficher / masquer l'élément d'un menu d'actions ; son nom est affiché dans l'arbre, les listes de modules et le rapport de vérification.
  • Style propre : un style prédéfini (défini une fois dans Styles) ou un style propre à l'élément (taille, espacements, texte, fond, bordure) pour chaque taille d'écran. Les menus, menus d'actions et onglets y ont des Couleurs des éléments, utilisées quand leurs Couleurs sont Propres ; les couleurs Inversées conviennent à un menu sur une bannière.

Les boutons de la ligne des onglets : ? affiche ou masque les textes d'aide du formulaire, la flèche détache le panneau dans une fenêtre (ou le rattache), × le ferme. Rattaché, le panneau est sous l'arbre, ou à côté des onglets Site et Page quand le volet de gauche est large. La fenêtre détachée est sur le bord gauche de l'écran et se ferme par un clic à l'extérieur (les modifications restent) ; Annuler revient à la page telle qu'elle était à l'ouverture, Appliquer garde les modifications, Rattacher remet le panneau à côté de l'arbre.

La plupart des modifications sont visibles tout de suite dans l'aperçu. La configuration d'un module (Explorer, Données, Carte, Chronologie, Graphe, Vue de fiche, Filtre) et ses Fiches et sélection sont appliquées avec Appliquer, car le module redémarre avec elles.

Tableaux croisés : un tableau croisé fait dans Explorer (outil Tableaux croisés). Dans son panneau, choisissez le tableau, l'origine de ses fiches (sa propre requête, les widgets Filtre de la page, les liens de filtres enregistrés ou un autre module : la dernière recherche compte) et ce que les visiteurs peuvent changer. Modifier dans une nouvelle fenêtre ouvre le tableau dans Explorer ; Actualiser montre les modifications faites là-bas.
