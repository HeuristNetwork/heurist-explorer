Heurist Reports

The reports manager lists the Smarty report templates of the database. A report is a Custom Report record (title, description, template file, card flag); the template text is kept in a file. Templates without a record are listed under Templates without a report record and can be given one.

Two kinds of report

  • Single record (card): shows one record. These reports are offered for record popups, cards and Record view in Map, Data, Graph and Record view.
  • Record set: a report over many records. It is not run on request: it is generated to a file in the background, and the file can be used in websites.

Editing a template

Choose a report and click Edit template. Place the cursor in the text, choose a record type on the right and click a field to insert it. The insert options decide whether the field name, a line break, a test for an empty value or a loop for repeating values are added. For an enumeration field choose its label, code or internal id. Insert pattern adds ready-made blocks (records loop, table, ...).

Test runs the template as it is in the editor (saved or not) on the selected records, or on the first 50 records of the current result. A single record (card) report is tested on one record only: the first selected record, or the first record of the result. The test can be stopped and has a time limit.

Generating and schedules

Generate writes a report for the current result or a Query Source to a file. It runs in the background: the progress is shown and Stop ends it. The generation continues when you close the reports manager or reload the page; when you come back, it is shown again with its progress. You can run one generation at a time. A new Test replaces a test that is still running. A schedule (Custom Report Schedule record) regenerates a report file from a Query Source at an interval. Only the owner group of a report and the database owner can add schedules. Scheduled reports contain public records only.
