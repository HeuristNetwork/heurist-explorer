Heurist Reports

The Report pane is the list of the Smarty reports of the database (the same list as crosstabs and story maps). A report is a Presentation set record of the kind Card Report or List Report (title, short summary, template file); the template text is kept in a file. New report asks the kind and opens the record editor; Import reads a .gpl or .tpl file. In the list the pen-and-ruler icon opens the template editor, the pen edits the record, the bin deletes the report (refused while it has generated reports). On the right: Test, Generate and ⋯ (Edit the template, Export) for the selected report, then its generated reports (a List Report) or a preview of the first selected record (a Card Report). With no report selected, the template files without a record are listed: register them or delete them.

Two kinds of report

  • Single record (card): shows one record. These reports are offered for record popups, cards and Record view in Map, Data, Graph and Record view.
  • Record set: a report over many records. It is not run on request: it is generated to a file in the background, and the file can be used in websites.

Editing a template

The template editor fills the whole screen; its toolbar is the one of all presentations: New report, the list of reports, the pen (the record), Save, Save as, Test, Generate (a List Report; the template is saved first), ⋯ Export; Close is on the header and asks about unsaved changes.

Open the editor of a report from the list. Place the cursor in the text, choose a record type on the right and click a field to insert it. The insert options decide whether the field name, a line break, a test for an empty value or a loop for repeating values are added. For an enumeration field choose its label, code or internal id. Insert pattern adds ready-made blocks (records loop, table, ...).

Test runs the template as it is in the editor (saved or not) on the selected records, or on the first 50 records of the current result. A single record (card) report is tested on one record only: the first selected record, or the first record of the result. The test can be stopped and has a time limit.

By default, report output may not run JavaScript or use style blocks: they are removed, and the toolbar shows "CSS and Javascript are disabled by default". The server administrator can authorise a database (file js_in_database_authorised.txt on the server); then scripts run in the output, e.g. the media viewer of image thumbnails.

Generating and schedules

Generate writes a report for the current result or a Query Source to a file. It runs in the background: the progress is shown and Stop ends it. The generation continues when you close the reports manager or reload the page; when you come back, it is shown again with its progress. You can run one generation at a time. A new Test replaces a test that is still running. A schedule (Custom Report Schedule record) regenerates a report file from a Query Source at an interval. Only the owner group of a report and the database owner can add schedules. Scheduled reports contain public records only.
